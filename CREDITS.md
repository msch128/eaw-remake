# Credits & Acknowledgments

**EAW:Remake** is an independent, open-source, non-commercial clean-room reimplementation of the *Empire at War* engine built in Rust and Bevy. It does not distribute any copyrighted game assets and requires a legitimate copy of the original game and mod.

## Engine & Open-Source Libraries

* **Rust Language & Toolchain**: The Rust Project Developers and the Rust community.
* **Bevy Engine**: Carter Anderson and the Bevy organization ([bevyengine.org](https://bevyengine.org)) for the world-class ECS, modern PBR rendering pipeline, and plugin architecture.
* **wgpu**: The gfx-rs community for cross-platform WebGPU-native graphics foundations.
* **Alamo Data & Reverse Engineering**: Clean-room file format decoders for Alamo file formats (`.ALO` 3D geometry, `.MEG` archives, Alamo XML specifications, `.DAT` string tables).
