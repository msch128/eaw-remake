# QA report 2026-10-08 - real-input playtest

Method: windowed `space-peace.exe` (build dde07e2, `target/playfix`) driven with real OS mouse and keyboard, sound muted,
window 2400x1350. Screenshots (game window only) and logs are kept outside the repo. Long-run checks: `tools/soak.ps1`.
Status is as of the last update of this file; "open" means no fix was verified yet.

## Worked in the live run
Main menu -> campaign select -> side dropdown -> Start; building a station upgrade (queued, credits deducted); pause and 2x
speed in galaxy and battle; fleet select + right-click order (route via an intermediate planet); battle banner Begin;
battle box select, right-click move, minimap click jump, wheel zoom, enemy hover bracket and name; F10 auto-resolve ->
victory and planet capture; Esc menu. 120-150 FPS.
