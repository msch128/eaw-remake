# Release checklist

Everything in this repository and on its Releases page is public. Before anything leaves the machine (a push of user-facing
docs, a README change, a release, a setup), go through this list. A step that does not pass blocks the release.

## Content
- [ ] No chat quotes, no German text, no profanity in commit messages, comments, docs or release notes
      (`gate-commit` refuses commit messages; check docs and notes by hand).
- [ ] No local paths or user names (`C:\Users\<name>`), no e-mail addresses, no tokens or keys.
- [ ] No game files: no models, textures, sounds, XML or other data from the game or the mod. Screenshots are allowed and
      carry the credit line in the README.

## Claims
- [ ] Every statement in README.md and the release notes matches the code and the release: features, install steps, file
      names, sizes, requirements, version numbers.
- [ ] Numbers (performance, scores) say how they were measured or that they are estimates.

## Binaries (setup on the Releases page)
- [ ] Built with `tools/package.ps1` from the commit the release tag points to.
- [ ] `THIRD-PARTY-LICENSES.html` is in the setup and attached to the release: the licence texts of every Rust crate in the
      program (generated by `cargo about`) and of embedded assets (Bevy's default font, Fira Mono, SIL Open Font License 1.1).
      `package.ps1` stops when it is missing.
- [ ] `tools/test-setup.ps1` passes: silent install, install check, offscreen start, uninstall.
- [ ] SHA-256 of the setup in the release notes; the SmartScreen note (unsigned setup) in README and release notes.
- [ ] Marked as pre-release while the project is a preview.
